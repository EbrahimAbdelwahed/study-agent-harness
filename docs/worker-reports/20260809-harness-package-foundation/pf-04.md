## Changed files

- `src/study_agent/api/storage.py` and `src/study_agent/ports/__init__.py`:
  canonical re-export of all six PF-04 ports plus typed outcomes; the facade
  no longer owns a duplicate `EventStore` protocol.
- `src/study_agent/ports/{storage,clock,id_factory}.py` and
  `src/study_agent/ports/__init__.py`: provider-neutral protocols, typed
  stale/conflict/not-found outcomes, aware-UTC validation, and host ID seam.
- `src/study_agent/adapters/memory/storage.py` and `__init__.py`: deterministic
  memory event/blob/run/repository adapters, fixed clock, and ID factory.
- `src/study_agent/adapters/sqlite/event_store.py`: optional registry for the
  envelope-only path, atomic idempotency records, rollback-safe append, and
  private SQLite failure translation; legacy PF-03 replay remains intact.
- `src/study_agent/adapters/sqlite/run_store.py`: typed operational CAS and
  not-found outcomes with private SQLite failure translation.
- `src/study_agent/adapters/filesystem/blob_store.py`: optional expected-ref
  verification, typed immutable blob failures, and private filesystem failure
  translation.
- `src/study_agent/{artifacts,assessments,courses,ingestion,recall,sessions,
  study_context}/**`: production event writers now use the private legacy
  no-key seam; public envelope writes require a non-empty idempotency key.
- `src/study_agent/adapters/sqlite/namespaced_run_store.py` and
  `src/study_agent/playbooks/engine.py`: preserve typed CAS conflicts through
  operational wrappers without boolean casts.
- `tests/contract/storage/test_storage_contract_kit.py`: shared memory/SQLite/
  filesystem scenarios for ports, keyed empty streams, idempotency, rollback,
  replay bytes, blob integrity, read-only authorization, CAS, UTC, IDs, and
  explicit repository composition.
- Existing event/blob fixtures were migrated to keyed public envelopes or the
  private legacy seam, and test doubles now implement the expected blob ref
  parameter.
