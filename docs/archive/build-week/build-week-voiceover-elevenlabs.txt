IF A SPOT STILL RUNS FLAT
  Do NOT add more break tags first — that is what destabilises the voice.
  Try in this order:
   1. swap the comma for an em dash (—) or ellipsis (…): free micro-pause
   2. split the sentence in two
   3. only then add a tag

IF YOU ARE ON ELEVEN V3
  Break tags are not supported. Replace every <break time="Xs" /> with [pause],
  which is not duration-controlled — so in that case prefer splitting the
  sentences and rely on generation-level assembly for exact timing.

VOICE SETTINGS
  Stability around 45-55: lower reacts more to the punctuation and the dashes,
  higher flattens the beats you just wrote in.
  Keep Speed at 1.0 — speed changes rescale the break tags too.
