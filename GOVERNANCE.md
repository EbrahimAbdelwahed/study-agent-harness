# Governance

Study Agent Harness is maintained through reviewable changes in the public
repository. There is no separate foundation, steering committee, or paid
support organization.

## Roles

- **Contributors** propose changes, tests, documentation, and issue reports.
- **Reviewers** check behavior, compatibility, security, and evidence.
- **Maintainers** merge approved changes, manage releases, and resolve
  community-health reports.

Maintainer membership and repository permissions are managed in the hosting
organization. A change that affects persisted contracts, public API, security,
or release trust requires explicit maintainer review and a durable decision or
release note.

## Decision process

Open an issue or pull request with the problem, scope, evidence, and proposed
verification. Discussion should converge on the smallest compatible change.
Maintainers may request an ADR under `docs/decisions/` for architectural or
schema decisions. Changes are merged only after required checks pass; no public
release, tag, or protected-branch push is implied by a merged pull request.
