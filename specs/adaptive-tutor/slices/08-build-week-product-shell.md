# Slice 08: Build Week product shell

## Outcome

A thin conversation-first consumer demonstrates free-form entry, material
population, grounded explanation, immediate assessment, learner evidence,
flashcard proposal, and review without becoming a second behavior layer.

## Contract

- Product code consumes public snapshot/capability interfaces only.
- UI never reads SQLite or calls model providers directly.
- Required states: working, suspended, conflicted context, needs review, stale,
  degraded, and recovered.
- One-command setup, sample data, deterministic offline journey, opt-in GPT-5.6
  smoke, and submission-quality README/video script are included.
