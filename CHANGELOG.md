# Changelog

Notable public changes are recorded here. Study Agent Harness is alpha
software; an entry describes released or explicitly prepared behaviour, not a
promise of publication.

## [0.2.0] — Unreleased source release candidate

- Added the contemporary Knowledge Base evidence pipeline while preserving the
  event stream as canonical state.
- Exposed the canonical course, source, session, evidence, artifact, and
  assessment owners through the framework-neutral agent tool surface.
- Preserved the original seven-tool compatibility boundary and made unavailable
  capabilities discoverable without pretending they are runnable.
- Added deterministic agent discovery, operator-skill extraction, lifecycle
  manifests, and the offline tutor-host demonstration.
- Archived the Build Week submission evidence separately from current release
  and installation guidance.
- Hardened packaging, clean-install verification, and release-facing project
  documentation for an OSS source candidate.

No tag, package upload, or online release is created by this candidate work.

## [0.1.0]

- Established the local-first event-sourced harness, immutable text ingestion,
  lexical retrieval, grounded-answer flow, typed tools, deterministic export,
  and reference CLI.
