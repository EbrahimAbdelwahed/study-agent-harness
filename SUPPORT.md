# Support

This project is an alpha open-source library. Support is community-based and
there is no guaranteed response time or hosted service.

Before asking for help:

1. read the [README](README.md), [integration guide](docs/integrations.md),
   [contributor guide](CONTRIBUTING.md), and relevant maintainer documentation;
2. reproduce the issue with the smallest offline fixture you can share; and
3. check existing issues and the changelog.

Use a public issue for reproducible bugs, documentation gaps, and focused usage
questions. Include the package version, Python version, platform, command or
API call, and a sanitized traceback. Never include credentials, private study
material, raw provider payloads, or sensitive vulnerability details. Follow
[`SECURITY.md`](SECURITY.md) for security reports.
